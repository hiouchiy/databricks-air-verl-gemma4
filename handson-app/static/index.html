2準備

      
最初に一度だけ実行します。データ準備は CPU のサーバーレスで動くので GPU は不要です（1分ほど）。
        終わると前提チェックの「データ」が ✅ になります。疎通確認は 1×A10 で学習用イメージを確認します（任意）。

      

    


    

      
3学習（GRPO）

      
まずは テキスト 単一ノード（約27分）から。2ノード版は 8×H100 を2台使います。
        終わったら必ずジョブが自動で終了します。途中でやめる場合は「停止」を押してください（GPU の課金が止まります）。

      

    

    


    

    

      
Aデータを指定する

      
Volume に置いた CSV / JSONL を指定します（1行 = 1問。質問と正解の列が必須、画像を使う場合は画像ファイルのパスの列）。
        正解は、数値・選択肢・短い語句のように短く1つに決まるものを想定しています。試すだけなら「サンプルの生データを作る」で練習用のデータを用意できます（CPU・約1分）。

C採点関数を決める

      
GRPO はモデルの答えに付けた点数だけを手がかりに学習するので、採点のしかたが学習の方向を決めます。
        型から選ぶか、採点の基準を書いてエージェント（UC のスキル + Claude + Sandbox）に作ってもらいます。最後に人が確認・承認したものだけが学習に使われます。
